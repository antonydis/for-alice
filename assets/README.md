# Artwork for Alice

Six illustrated memories and one walking spritesheet in optimized WebP format.

| File | Moment |
| --- | --- |
| `stadium.webp` | Our first soccer date |
| `hike.webp` | Walking through the autumn landscape |
| `cinema.webp` | At the movies together |
| `ramen.webp` | Ramen and Chinese desserts |
| `birthday.webp` | Arepas, empanadas and a birthday |
| `dance.webp` | Our first dance class |
| `walk-atlas.webp` | Four positions of the capybara couple, in a 2×2 grid |

The artwork is optimized for the mobile site and carries no labels or overlays. The characters are the capybara with a blue sweater and the capybara with a knitted purple cardigan and cream shirt.
